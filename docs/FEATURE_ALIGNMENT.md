# 申请书功能对照与验证

依据：用户提供的《广州大学_基于AI大模型的校园智能交友聊天小程序——“Synaptic Pulse｜隙湃”(5).docx》。这是产品参考，文档中关于模型、平台和实验的描述不等于当前已实现能力。沿用现有 uni-app x 用户端与 Spring Boot 服务器端。

## 当前功能

| 申请书中的方向 | 本次落实 | 当前范围 |
| --- | --- | --- |
| 首页动态问候与功能入口 | 按本地时间问候，校园活动 / 社交练习可进入，兴趣推荐给出共同标签和理由 | 采用 Jaccard 基线；不表示 AI 预测的交友成功概率 |
| 兴趣圈搜索与互动 | 按正文、话题、作者和地点名称搜索；九图、评论、点赞、复制分享；删除本人动态 | 动态最多 50 条，评论最多 100 条；分享是复制文字 |
| AI 辅助发布与草稿 | 文字 / 图文切换、本地选图、Web 拖拽、话题、地点名、草稿恢复和发布预览 | 未配置模型时明确显示本地规则建议；没有图片编辑、定位或可见范围权限 |
| 聊天历史与未读 | 会话时间 / 未读数 / 本地会话筛选；文字历史搜索、加载更早消息、图片、表情和本地 GIF；输入草稿 | 每 5 秒拉取；关闭自动刷新后可手动刷新；没有群聊或 WebSocket |
| 活动组织 | 发起同校活动、搜索、显示安排地点 / 时间 / 名额、报名与取消、发起者删除 | 服务端事务控制名额；仅允许开始时间之前新报名 |
| 分级社交训练 | 新手 / 进阶 / 专家，4 个校园场景，多轮对话、表达建议、次数与难度进度 | 本地规则可用；模型服务需配置及用户同意；不提供未经验证的心理、情绪或能力分数 |
| 我的成长空间 | 头像、院系专业与年级、分类兴趣与自定义标签、性格自述、交友目的、交流与活动偏好、空闲时间、发帖 / 练习 / 双向对话计数、基础脉冲和成就 | 不是研究模型效果评估，也没有积分兑换 |
| 常用设置与个性外观 | 原经典风格保留；切换 Liquid Glass 风格；自动刷新、服务器地址、屏蔽管理、清除本机草稿 | Web 毛玻璃使用背景模糊与半透明层；其他平台效果待实机验收 |
| 校园地图与附近活动 | 18 个公开地点、分类搜索、收藏、可选定位、250 / 500 / 1000 米查询、活动地点关联与波纹、任意选点图文动态及评论入口 | 桌面 Web / Android 共用 Leaflet 页面；附近在线用户、路径导航、匿名漫游、AR 尚未实现；真机定位待验收 |

### 成长规则

- 脉冲 = `min(本人当前动态数,50)×2 + min(练习数,20)×5 + 双向对话数×10`。
- 双向对话为同一会话至少 6 条消息，且双方都发送过消息；不做内容质量判断。
- 有动态获得“突触先锋”；有双向对话获得“脑波同频者”；至少 3 次练习获得“社交练习者”。
- 同一轮练习使用同一个 `practiceId`，继续对话不重复计数。切换场景 / 难度或开始新一轮会使用新标识。
- 这些是展示当前活动量的原型规则，删除动态会影响其计数，不是不可撤销的积分账本。

## 修复与防护

| 问题 | 处理 |
| --- | --- |
| 登录令牌失效后仍停留原页 | API 401 清除令牌并返回登录；更换服务器要求重新登录 |
| 空响应引发 JSON 解析异常、自定义导航在子页面重复隐藏 TabBar | 请求封装单独处理空响应；导航只在 TabBar 页面隐藏系统栏 |
| 草稿被不同账号混用、临时图片失效 | 草稿按服务器和账号隔离；保存图文草稿先上传图片并保存 URL |
| 网络重试重复发消息 | 客户端保存失败消息的 `clientId`；数据库唯一键保证同一发送者重试只产生一条消息 |
| 图片越权使用 | 头像、图文发布与聊天附件均校验上传者；服务端校验文件类型与单张大小 |
| 聊天页面退出后轮询、请求重叠 | 页面隐藏 / 卸载清理定时器；请求完成后再安排下一次刷新；保留已加载的旧消息 |
| 已读位置被旧请求倒退 | 服务端只允许已读位置向前；限制在真实收到的消息范围内 |
| 评论面板切换时显示错帖 | 异步响应核对当前帖子；重新打开获取最新评论；过滤被屏蔽作者 |
| 并发报名超过活动容量 | 在事务中锁定活动行，检查截止时间和容量，再写入唯一报名记录 |
| 错误日期或过长 UTF-8 密码触发服务器异常 | 输入格式返回 400；bcrypt 密码字节长度明确检查 |

## 验证记录（2026-10-02）

- `backend/mvnw.cmd test`：6 项测试通过，失败 0、错误 0。
- 测试包括 55 条聊天消息的历史分段、未读 / 已读和重复重试；两个账号竞争单个活动名额；图片归属、无效文件、点赞幂等、删除权限；练习去重及未配置 AI 的明确响应。
- HBuilderX 5.26 Web 开发编译成功；旧 H2 文件数据库可正常启动并加载新增字段与表。
- 浏览器实操：本地选图、一次拖入超过余量时保持最多 9 张；保存图片草稿后刷新恢复；发布 / 预览、地点搜索、点赞、跨账号评论及回复；55 条未读消息、加载更早历史、关键词搜索、文字 / 表情 / 图片发送，返回列表未读归零；活动发布 / 报名 / 取消；分级练习多轮计数；头像更新与主题刷新后保留；失效令牌返回登录页。使用独立的 8089 内存数据库和体验账号，不写入原有业务数据。
- 手机宽度下检查了设置与聊天的 Liquid Glass 界面；最后检查聊天页面控制台为 0 个错误、0 个警告。设置、聊天与九图社区的截图仅保留在本地。
- Android、微信小程序与真实模型调用尚未验收，Web 开发编译不能代替跨端验收。HBuilderX 类型检查仍有生命周期导出提示，Web 浏览器运行正常，跨端构建需继续核对。
