# 校园地图第一版

## 选型

采用 Leaflet 1.9.4、共用 HTML 地图界面和 Java 地点接口。当前主要需求是二维校园地点、活动点位和距离查询，暂不引入 WebGL 或独立原生地图 SDK。桌面 Web 和 Android WebView 使用同一界面；后续桌面安装包可以复用，但目前没有新增 Windows 原生安装包。

## 已实现

- 首页“校园地图”入口；桌面宽屏地图与侧栏、手机上下布局。
- 18 个广州大学大学城校区地点，按学习、运动、餐饮、文化、休闲、服务分类；关键词搜索与地点详情。
- 地点收藏保存在服务端，按账号区分。
- 点击“我的定位”后才请求位置；Web 使用浏览器定位，Android 使用 `uni.getLocation(type: 'wgs84')` 并通过 WebView 上下文传入地图。
- 以校园参考中心、地图中心、选中地点或本人定位查询附近；250 / 500 / 1000 米可选。未定位时明确显示“参考中心”，不会把校园中心伪装成用户位置。
- 活动发起时可选择地图地点；地图展示有明确地点关联、尚未开始且对当前用户可见的活动，可查看地点、报名和取消报名。
- 只有真实活动点位显示动画波纹，没有生成假用户或虚构活动。
- 地图沿用设置中的经典 / Liquid Glass 外观；不额外改变用户的主题偏好。

## 文件与数据流

| 文件 | 作用 |
| --- | --- |
| `client/pages/map/map.uvue` | uni-app x 页面容器、返回 / 地点选择和原生定位桥接 |
| `client/common/campus-map.js` | 地图地址和地点选择入口 |
| `client/static/campus/` | 共用地图 HTML、CSS、JS、GeoJSON、固定版本依赖 |
| `backend/.../CampusMapController.java` | 登录校验、地图数据与收藏接口 |
| `backend/.../CampusMapService.java` | 地点导入、距离计算、同校范围和收藏 |
| `backend/src/main/resources/map/places.json` | 有来源链接的初始地点目录 |
| `scripts/import-campus-osm.py` | 将 OSM XML 提取为校园矢量底图与初始地点目录 |

地图页面通过项目服务器的 `/campus/index.html` 加载。Maven 会把 `client/static/campus` 复制进后端 JAR；修改这部分资源后需重新构建 / 启动后端。页面与接口仍需要项目服务器可连接，“本地校园底图”指不依赖外部瓦片服务，不代表整个应用离线可用。

登录令牌通过 URL fragment 传入，网页初始化后移除 fragment，只在内存保留。令牌不写入请求 URL、地图 localStorage 或第三方地图请求。Web 消息接收同时核对来源 origin 和 iframe；原生消息只处理固定动作。

## 初始地图来源

OSM 地点和道路 / 建筑轮廓取自公开 API：
`https://www.openstreetmap.org/api/0.6/map?bbox=113.363,23.032,113.377,23.044`，获取日期 2026-10-02。

本次提取 18 个地点、441 个矢量要素；坐标采用 WGS84。建筑点位采用边界顶点的代表中心，不能代替真实入口。初始数据不是学校官方认证地图，实际使用前应由维护者核对校名、地点位置和入口；开放时间与可通行路线仍以现场为准。数据署名、许可及来源见 `client/static/campus/THIRD_PARTY.md`。

默认显示随服务器分发的校园矢量底图，可选切换 OSM 街道瓦片。切换街道底图会向外部瓦片服务发送所查看区域的瓦片请求；不向它发送站内令牌或账号资料。公共瓦片不提供可用性保证，没有下载离线瓦片或批量预取。正式部署可替换 `map.js` 中的瓦片服务，需遵守对应服务条款。

## 当前边界

- 附近活动是按地点计算的直线距离，不是步行路径规划。
- 旧活动只有自由填写的地点名，不会凭名称自动推断坐标；新活动明确选择地图地点后才出现在地图。
- 当前最多关联活动列表中的 50 场活动；后续可增加按范围分页的活动查询。
- 不展示其他人的实时位置，未实现匿名漫游、附近在线用户、AR 或校区间路线。
- 用于附近查询的定位坐标不写入业务数据库；关闭页面不继续定位。部署访问日志也应避免记录精确位置查询参数。
- Web 定位通常需要 HTTPS 或 localhost，并由用户授予权限。Android 正式包的位置权限、系统提供者与真机行为仍需逐设备验收。
- 地点目录只覆盖广州大学大学城校区；其他学校或校区需要补充数据。

## 任意位置图文动态（2026-10-02）

- 点击地图顶部“标记发帖”，再点击任意位置；标记可以拖动微调。填写名称后进入现有发布页，支持纯文字或最多九张图片的图文动态、电脑拖入本地图片。
- 发布页也可进入地图选择 / 更换任意坐标，移除标记；草稿保留坐标，位置名称可编辑。选点不需要真实定位权限。
- 地图“位置动态”列表和地图图标提供图片九宫格缩略图、原文 / 评论入口；详情页支持大图预览、点赞、评论、本人删除。在同一位置继续发帖时直接复用坐标。
- 经纬度采用 WGS84，全局有效范围可选；校园之外需切换街道底图才有对应地理背景。初始本地矢量数据仍只覆盖广州大学大学城校区。
- 同校位置动态按双向屏蔽和附近半径筛选，筛选后最多返回最新 100 条；重叠位置的多条动态可从详情或列表访问。旧帖子没有坐标，不推断其位置。
- 主动发表的位置标记随帖子保存并公开展示，与用于当前查询的实时定位不同；没有采集或公开实时用户轨迹。

新增 `client/pages/post/post.uvue` 为单条帖子详情页，`PostController` 保存可选坐标及处理地图动态查询。数据库启动时增量增加可空字段，不删除已有内容。
